# 藥物基因體學互動導覽

用 three.js 3D 互動場景，由淺入深認識藥物基因體學（Pharmacogenomics）。繁體中文（台灣）。

| 層級 | 章節 |
|---|---|
| **L1 入門** | 01 同一顆藥，為什麼效果不一樣？ · 02 從 DNA 到蛋白質 |
| **L2 初階** | 03 等位基因、基因型與表現型 · 04 藥物在身體裡的旅程 |
| **L3 中階** | 05 CYP450：肝臟裡的代謝工廠 · 06 氯吡格雷、可待因與華法林 · 07 HLA 與嚴重藥物過敏（台灣的重要發現） |
| **L4 進階** | 08 族群差異與台灣 · 09 從檢測到處方（臨床與倫理） · 10 腫瘤、多基因與 AI |

每章都有：可操作的 3D 場景（隨文字捲動同步變化）、重點整理、進階可收合內容、小測驗，以及參考來源。另有術語表（可搜尋、依難度篩選）與資源頁（含台灣藥物基因體學會 PGST、臺大醫院藥物基因體與智慧用藥網等）。

> 本站內容僅供教育與科普，不構成醫療建議。

## 開發

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # 產出 dist/（相對路徑，可放任何靜態空間）
npm run preview
```

### 品質工具（`scripts/`）

```bash
node scripts/smoke.mjs ch05 [--mobile] [--steps]   # 自動操作控制項/滑鼠/捲動步驟，截圖到 test-output/，偵測錯誤與空白畫面
node scripts/smoke.mjs all                          # 整頁測試（全部章節）
node scripts/viewports.mjs ch05                     # 七種視窗尺寸截圖（1440/1366/1024/平板/手機/橫向手機）
node scripts/overflow.mjs ch05 --width 360          # 找出造成水平溢出的元素
node scripts/check-content.mjs [--quiz]             # 內容靜態檢查：術語連結、step 連號、測驗（含選項長度偏誤）、簡體字與中國用語
node scripts/normalize-punct.mjs [--write]          # 中文旁的半形標點 → 全形
```

煙霧測試使用系統的 Chrome/Edge（軟體 WebGL，速度慢但可用），不需另外下載瀏覽器。

## 結構

```
src/main.js               組裝頁面（導覽、Hero、學習地圖、章節、術語表、資源）
src/core/                 Stage（可回收的 three.js 舞台）、ui 控制項、util 工具、palette 顏色語法、章節渲染、測驗、術語提示
src/content/chNN.js       章節文字內容（資料）
src/content/glossary/     術語表（自動合併；每個術語只在最先需要它的章節定義一次）
src/scenes/chNN.js        章節的 3D 場景（chNN/ 資料夾放輔助模組）
research/                 查證過的事實庫（內容唯一依據；每則事實有來源與查證狀態）
docs/CONTRACT.md          開發契約（場景 API、內容格式、寫作與驗收規則）
docs/BRIEFS.md            各章設計簡報
```

新增章節：新增 `src/content/chNN.js` 與 `src/scenes/chNN.js` 即可，不需修改註冊表。

## 設計重點

- **舞台（Stage）**：每個 3D 場景各自有 renderer，但只在靠近視窗時才建立、離開後釋放（同時最多 4 個），所以整頁十幾個場景不會耗盡瀏覽器的 WebGL context；context 遺失會自動恢復。
- **版面**：桌機為「文字＋黏頂 3D 舞台」雙欄；平板/手機（≤1100px）舞台黏在導覽列下方，讀到哪段文字場景就同步變化，控制項收在「⚙ 互動控制項」抽屜。
- **無障礙**：3D 畫面可用鍵盤聚焦（方向鍵旋轉、Home 重設）；控制項有標籤、方向鍵切換；術語提示與圖說會以節流後的文字播報；重要資訊不只靠顏色。
- **內容誠信**：數字與臨床陳述必須追溯到 `research/*.verified.json`；示意性數據在畫面上一律標「示意」；未經獨立查證的事實只以「依某來源」的方式引用。

## 已知限制

- 場景內「滑過/點擊物件顯示提示」只有指標可用（鍵盤使用者可旋轉場景，但無法逐一檢視物件提示；重要資訊都另寫在文字與圖說中）。
- 開啟 `prefers-reduced-motion` 時，環境裝飾動畫會減弱，但場景內的模擬動畫仍會播放（有「暫停動畫」按鈕）。
- 少數 Taiwan 官方網站（TFDA、部分衛福部頁面）在資料整理時無法從境外開啟，相關健保給付條件請以最新官方公告為準。
- 各章「參考來源」的數字取自 CPIC 頻率表（文獻加權平均）或特定研究（多為醫院世代），不等於台灣全體人口的實測值，章內皆有標註。

## 主要資料來源

CPIC / ClinPGx（PharmGKB）、PharmVar、FDA、台灣藥物基因體學會（PGST）、衛福部、健保署、台灣人體生物資料庫、臺大醫院藥物基因體與智慧用藥網，以及各章末列出的原始文獻。
