## ch01 同一顆藥,為什麼效果不一樣?(L1,引子)
**學習目標**:知道「同藥同劑量,人人反應不同」是常態;基因只是其中一個(重要且可檢測的)因素;藥物基因體學想做的事;知道它有三種作用途徑(藥物怎麼被處理 / 藥物作用的目標 / 免疫過敏)——只點到為止。
**故事**:三個人吃同一種藥的三種結局(有效/沒效/嚴重副作用)。台灣角度預告(卡巴馬平與 HLA-B*15:02,只預告)。
**場景「藥物反應人群」**:廣場上約 60 個簡化人形(用 InstancedMesh 或群組,相機略俯視)排成弧形/網格,中央有一顆發光的大藥丸。
- 控制:`按鈕「大家一起吃藥」`(藥丸分裂成小藥丸飛向每個人,人形依結果亮起:有效=綠、沒效=黃灰、副作用=紅,每種結果有小動畫:綠色光環上升、紅色閃爍警示);`分段「用什麼因素來看這群人」`:無 / 年齡 / 體重 / 肝腎功能 / 併用藥物 / 基因型——選擇後人群依該因素**重新排列分組**(平滑動畫),並顯示每組結果分布。**示意**資料須明確標示「模擬示意,非真實統計」。基因型分組時呈現最乾淨的分群(讓讀者「看見」基因的解釋力,但要用文字說明:這只是示意,真實世界不會這麼乾淨,基因只解釋部分變異——用事實庫的數字)。
- `hud.legend` 顯示三種結果顏色;`readout` 顯示各結果人數。
- steps:0 初始(人群+藥丸)/1 吃藥→結果分布/2 換因素看分組(年齡等)/3 基因分組/4 個別化用藥(綠色人數變多的對照)。
**必備內容區塊**:一個 `facts`(Schork 2015 那類的數字——僅限已驗證者)、`compare`(一體適用 vs 個人化)、`callout taiwan`、`keypoints`、`quiz`。

## ch02 從 DNA 到蛋白質:遺傳的語言(L1)
**學習目標**:DNA 是四種鹼基寫成的密碼;基因→mRNA→蛋白質(中心法則);一個字母的改變(SNP)可能改變蛋白質;蛋白質就是處理藥物的酵素/受體/轉運蛋白。
**場景「解讀密碼」**:一段雙股螺旋 DNA(`util.createDNA`),攝影機由遠拉近。
- 流程按鈕/滑桿(`進度` 0–4):① 螺旋 ② 解旋(`setOpen`)③ 轉錄:沿一股長出 mRNA(U 用 `COLORS.U`)④ mRNA 離開細胞核進入核糖體 ⑤ 翻譯:三聯密碼子逐一讀取,對應胺基酸珠串增長並折疊成蛋白質。
- 「突變實驗」:點擊某個鹼基(或用分段按鈕選 A/T/G/C 替換選定位置),密碼子改變,若胺基酸改變則蛋白質串珠中該顆變色並造成外形變形(示意),同義突變則不變;`hud.caption` 說明是「錯義/同義/無義」。密碼子表用完整標準遺傳密碼(64 碼)。
- 提供 `readout`: 目前密碼子 → 胺基酸。
- steps 對應上面五階段 + 突變。
**注意**:別把 DNA 畫得太複雜;重點是清晰的「流程感」。核糖體用兩個半透明橢球+通道即可。

## ch03 等位基因、基因型與表現型(L2)
**學習目標**:我們每個基因有兩份(父母各一);等位基因、基因型、星號命名、雙倍型;功能分級(正常/降低/無功能/增加);基因型→(活性分數)→表現型(代謝型);遺傳機率。
**場景「基因型實驗室」**:一對染色體(母源/父源,不同色 X 形)上有一個發亮的基因座(以 CYP2C19 為範例),放大顯示。
- 控制:兩個 `分段`(來自母親的等位基因 / 來自父親的等位基因:`*1`、`*2`、`*3`、`*17`),即時顯示雙倍型 `*1/*2`;基因座旁的「酵素工廠」依等位基因功能長出:正常=標準酵素分子、無功能=灰色殘缺分子、增加功能=更多且發亮分子。旁邊有活性量表與**表現型徽章**(顏色依代謝型),並以 `readout` 顯示活性分數(以事實庫的 CPIC 對應為準)。
- 「遺傳」模式(`toggle`):選兩位家長的雙倍型,顯示 4 種子代組合(Punnett),各 25%;點某個子代看其表現型。
- steps:0 染色體與基因座 / 1 一個基因兩個等位基因 / 2 星號命名 / 3 功能→酵素量 / 4 雙倍型→表現型 / 5 遺傳。
**必備**:一個 `table`(CYP2C19 雙倍型→表現型,以 CPIC 最新版驗證為準)、Hardy–Weinberg 的 `deepdive`(含算例)。

## ch04 藥物在身體裡的旅程(L2)
**學習目標**:ADME;PK(身體對藥物做什麼) vs PD(藥物對身體做什麼);血中濃度-時間曲線與治療窗;基因可能影響哪些環節。
**場景「一顆藥的旅程」**:半透明簡化人體(用基本幾何:軀幹、頭、四肢輪廓,不要求真實解剖),內部有胃、腸管(一條彎曲管)、肝、心、血管路徑(TubeGeometry)、腎、膀胱。一顆藥丸沿路徑前進:口→胃(溶解成顆粒)→小腸(吸收:顆粒穿過腸壁進入血流)→肝門靜脈→肝(首渡代謝:部分顆粒變色/消失)→心→全身(分布到目標組織,發光)→腎(排出)。粒子數量隨路徑遞減以展現濃度變化。
- 控制:`播放/暫停`、`速度`、`分段:給藥途徑(口服/靜脈注射)`(靜脈略過吸收與首渡)、`滑桿:肝代謝速率 50%–200%`;疊一張 `createChartPlane` 濃度-時間曲線(即時描點、含治療窗色帶:太低=無效、太高=毒性),曲線隨代謝速率改變(先預告基因影響,ch05 再深入)。
- steps:0 全景/1 吸收/2 分布/3 代謝/4 排除/5 曲線與治療窗/6 「基因可能改變哪裡」。攝影機隨 step 平滑聚焦。
**必備**:ADME 四字圖解 `steps` 區塊、PK vs PD `compare`、治療窗說明、半衰期、`deepdive`(一室模型公式)。

## ch05 CYP450:肝臟裡的代謝工廠(L3)
**學習目標**:CYP450 是什麼、負責哪些藥;五種代謝型;前驅藥 vs 活性藥的相反後果;抑制劑/誘導劑與「表現型轉換」(phenoconversion)。
**場景「肝細胞工廠」**:肝細胞剖面(細胞膜+內質網膜),膜上鑲嵌許多 CYP 酵素(藍色、帶血基質亮點)。藥物分子(橘)從一側通道流入,碰到酵素被轉化成產物(依模式:前驅藥→活性=青綠;活性藥→失活=灰)。
- 控制:`分段:代謝型 UM/RM/NM/IM/PM`(改變酵素數量/活性,顏色依代謝型),`分段:藥物類型(活性藥 / 前驅藥)`,`toggle:加入 CYP 抑制劑`(酵素被「堵住」,NM 變得像 PM),`滑桿:劑量`,`readout:血中藥物濃度 / 活性代謝物濃度`;側面一張 `createChartPlane`,同時畫出五種代謝型的濃度曲線(顏色依 palette),目前選擇者加粗,並繪出治療窗,清楚看到「PM 的活性藥堆積到毒性區;PM 的前驅藥根本轉不出足夠活性物」。使用簡單的一室 PK 模擬(JS 內數值積分)驅動曲線與粒子流速。
- steps:0 肝細胞/1 酵素與藥物/2 五種代謝型/3 前驅藥 vs 活性藥/4 抑制劑/5 總結。
**必備**:CYP 家族負擔藥物比例(事實庫已驗證者)`facts`、活性分數 `table`、DDI 例子 `callout clinical`、`deepdive` 講 phenoconversion。

## ch06 經典案例:氯吡格雷、可待因與華法林(L3)
**學習目標**:從三個真實案例看基因如何改變處方與風險,明白指引長什麼樣子(CPIC 等級/建議)。
**場景「案例探索器」**:`分段:藥物`(氯吡格雷/可待因/華法林)+ `分段:基因型/代謝型`。三個子場景共用 stage:
- 氯吡格雷(前驅藥,CYP2C19):血管切面,血小板漂浮;活性代謝物阻斷血小板受體 → 不聚集(綠);PM 產生的活性物少 → 血小板聚集成栓塞(紅)。
- 可待因(前驅藥,CYP2D6 → 嗎啡):腦部受體示意;UM 嗎啡過量(受體大量占滿+警示,兒童風險);PM 鎮痛不足。
- 華法林(CYP2C9 代謝 + VKORC1 靶點):維生素 K 循環示意/劑量需求條(依基因組合,以事實庫或指引為準;若無驗證的數值,只做定性方向)。
- 右上角 HTML `hud.caption` 顯示 **CPIC 建議摘要卡**(指引年份+證據等級+建議文字,取自 verified 事實)。
- steps 對應三個藥各一段 + 總覽。
**必備**:`table`(其他重要配對:他汀類/SLCO1B1、SSRI、PPI、他莫昔芬…,取自事實庫)、`callout warn`(FDA 標示/警語,已驗證者)、`callout clinical`、`deepdive` 講證據爭議(如華法林試驗結果、他莫昔芬)。

## ch07 HLA 與嚴重藥物過敏:台灣的重要發現(L3)
**學習目標**:HLA 是「細胞的身分展示櫃」;特定 HLA 等位基因 + 特定藥物 → 免疫誤判;台灣團隊的貢獻(卡巴馬平/HLA-B*15:02);為何篩檢有意義,以及「帶有等位基因≠一定發病」(PPV/NPV);其他高風險配對(表格)。
**場景「免疫辨識」**:細胞表面的 HLA 分子(凹槽抓著胜肽的示意)+ 上方的 T 細胞受體(TCR)。
- 控制:`分段:HLA 類型`(有風險等位基因 B*15:02 / 其他 HLA-B),`toggle:加入藥物(卡巴馬平)`;有風險 HLA + 藥物 → 藥物分子嵌入凹槽、改變呈現的胜肽形狀 → T 細胞辨識為異物 → 活化(發光、釋放細胞激素粒子)→ 皮膚受損示意(表皮層剝離,不需血腥)。其他 HLA + 藥物 → 無反應。需明確標「示意:實際分子機制仍有多種假說」(以事實庫為準)。
- 第二個模式 `分段:模式(機制 / 篩檢的意義)`:篩檢模式用 1,000 個點(InstancedMesh 點陣 40×25)表示一群將接受藥物的人,依事實庫數據標出攜帶者、發生嚴重反應者,顯示「篩檢後避開用藥」前後差異(必須引用 Chen 2011 NEJM 等已驗證數據;若無驗證數字,改為定性示意並標示)。
- steps:0 HLA 是什麼/1 正常呈現/2 藥物介入/3 T 細胞活化與症狀/4 為何只有部分人發病/5 篩檢的效果。
**必備**:`callout taiwan`(健保給付檢測、Chung 2004 等,以事實庫已驗證者為準)、`table`(HLA-藥物配對與族群頻率概況;TPMT/NUDT15、DPYD、G6PD 等代謝毒性配對)、`deepdive`(機制假說:p-i 概念、改變胜肽庫、半抗原)。

## ch08 族群差異與台灣(L4)
**學習目標**:等位基因頻率因族群而異(起源、遷徙、選擇、瓶頸);台灣族群的特色;為何同一種藥在不同地區風險不同;為何不能用「種族」代替基因型。
**場景「基因地球」**:可旋轉的 3D 地球(球體+經緯線+簡化大陸點陣/多邊形輪廓——可用程式產生粗略點陣陸地,或內嵌簡化陸地 GeoJSON 的抽象版本;檔案大小控制在 50KB 內),各區域(東亞、台灣、東南亞、南亞、歐洲、非洲、美洲…)以立柱表示所選等位基因的頻率(高度+顏色漸層,數值標籤在點擊/懸停時顯示,附來源與樣本說明)。
- 控制:`select` 基因/等位基因(以事實庫有可靠多族群數據者為準:CYP2C19 *2/*3/*17、CYP2D6*10、HLA-B*15:02、HLA-B*58:01、NUDT15 R139C、VKORC1 -1639G>A 等),`分段:顯示(等位基因頻率/表現型頻率)`(若數據支援)、`toggle:標出台灣`。地球點台灣時鏡頭飛近。
- 同時提供 `bars` 內容區塊作為無障礙與精確對照。
- steps:0 地球/1 CYP2C19/2 CYP2D6/3 HLA-B*15:02/4 台灣焦點/5 為何會有差異。
**限制**:不得使用事實庫沒有的頻率數字;缺數據的區域顯示「無資料」而非猜測。

## ch09 從檢測到處方:臨床實務與倫理(L4)
**學習目標**:實際如何從一管血變成處方建議;檢測技術比較;前瞻式 vs 反應式;指引機構(CPIC、DPWG、FDA);限制與倫理(隱私、歧視、公平、知情同意);病人該怎麼做。
**場景「基因檢測流水線」**:一條 3D 流水線(俯視斜角)串起站點:採檢(採血/口腔拭子)→ DNA 萃取(離心管)→ 基因檢測(依技術)→ 資料判讀(星號等位基因)→ 對應表現型 → 臨床決策支援(醫囑警示)→ 處方調整。一根試管沿軌道行進,經過各站亮起並顯示小標籤。
- 控制:`分段:檢測技術`(即時 PCR/TaqMan、基因晶片、次世代定序):切換第 3 站的視覺(PCR 熱循環儀、晶片格點、定序流動槽)並在 `hud.caption` 說明優缺點(通量、成本、可偵測變異型態);`分段:病人情境`(如 ACS 患者接受氯吡格雷 / 兒童可待因 / 癲癇患者使用卡巴馬平 [台灣] ——情境須與指引一致並取自事實庫)沿流水線得出「建議」HTML 卡片;`toggle:前瞻式檢測`(顯示基因結果存入病歷,日後開藥自動提醒)。
- steps:0 流水線總覽/1 採檢/2 萃取/3 檢測/4 判讀/5 決策支援/6 結果與倫理。
**必備**:`compare`(前瞻 vs 反應)、`table`(指引機構比較)、`callout warn`(檢測的限制與倫理,含台灣法規名稱——以事實庫驗證為準)、`callout tip`(給病人的建議:不要自行停藥…)。

## ch10 前沿:腫瘤、多基因與 AI(L4)
**學習目標**:體細胞(腫瘤)vs 生殖細胞藥物基因體學;為何多數藥物反應是多基因的;GWAS;AI 的潛力與限制;未來:預防性檢測、多樣性資料庫、台灣的計畫。
**場景「前沿導覽」**:`分段` 三個主題,共用一個 stage:
1. 「腫瘤標靶」:腫瘤細胞與 EGFR 受體(酪胺酸激酶);突變版 EGFR 持續啟動增殖;標靶藥物嵌入 ATP 口袋→訊號中斷(示意);切換「野生型/突變型 × 有無藥物」四種組合的結果。
2. 「GWAS 曼哈頓景觀」:程式產生的基因體地形(22+X 染色體交替色柱狀 3D,高度=−log10 p),以示意資料呈現少數尖峰(標示為「示意」);選擇性狀時對應尖峰亮起,說明「小效應疊加(多基因)」;若事實庫有華法林 GWAS 的已驗證結論(VKORC1/CYP2C9/CYP4F2 三峰),可據以標註。
3. 「AI 與資料」:節點網路(基因—藥物—反應)+ 資料多樣性長條(事實庫已驗證的 GWAS 族群比例),強調 AI 的限制(訓練資料偏誤)。
- steps 對應三主題 + 未來展望。
